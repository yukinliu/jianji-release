# 见己·自我觉察与成长记录

见己是一款本地优先的个人记录软件。分别留下感受、想法与真实经历，通过单日、项目和时间回看，慢慢更理解自己。

v0.2.3 修复资料库新建与切换、启动问候语重复，以及 Windows 启动时出现黑色窗口的问题。

## 本仓库的用途

本仓库公开提供安装包、签名更新文件、版本信息和隐私说明。完整桌面源码保存在私有仓库中，不在这里公开；本仓库不保存用户记录或私钥。

- Releases：各版本原包、更新归档、签名、updater.json 与校验值。
- daylog-content.json：客户端版本提示、更新说明及固定入口。

发布前先完成验证，并确认飞书下载页已就绪；再发布 Release 和版本提示。更新签名与操作系统代码签名不同，遇到安装问题可查看飞书说明。
