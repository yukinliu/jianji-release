见己隐私说明

更新日期：2026年10月27日
适用：见己桌面端 v0.2.2，包括 Microsoft Store 版

见己由刘迷糊开发和维护，用于记录与回看个人感受、想法、经历和项目复盘。

你的记录保存在所选资料库

感受、想法、事件、项目及复盘保存在你选择的本地文件夹中，采用 JSON 和 Markdown 文件。见己不将这些记录的正文、感受值、项目名称、资料库路径或文件上传到我们的服务器。使用软件不需要注册见己账户。

软件在设备上保存最近打开的资料库位置、外观设置以及部分未保存输入，以便继续使用。请复制整个资料库进行备份；设备上的临时输入缓存不等同于备份。若你自行选择同步盘或分享资料库，相关文件的同步与共享由该服务及你的设置决定。

少量使用统计

见己通过 TelemetryDeck 接收少量匿名使用统计，用于了解软件是否能正常使用以及改进产品。事件限于首次启动、每日打开、首次保存想法、首次保存事件、点击更新入口和反馈入口。发送内容包括匿名随机标识、应用版本、操作系统平台、事件类型和事件日期，不包含你的记录正文、感受值、项目名称、姓名、邮箱或文件路径。

统计服务为 TelemetryDeck（https://telemetrydeck.com/privacy/）。请求通过 HTTPS 发送；服务接收网络请求时会处理传输所需的网络信息。统计失败不影响本地记录。设备上最多暂存20条待发送事件，后续启动或记录相关操作时重试。我们不使用这些统计提供广告或建立基于记录内容的个人画像。

联网与外部页面

软件会从 GitHub、Gitee 和 jsDelivr 获取版本信息与产品内容。直接下载版可从 GitHub 下载并校验更新；Microsoft Store 版由微软商店管理安装和更新，不运行直接下载版的更新安装器。微软商店对账户、购买或分发信息的处理适用微软的隐私政策。

你主动打开使用指南或反馈入口时，会在浏览器访问飞书页面。只有你自行向反馈页面提交的信息才会通过该入口提供给我们；请避免提交不必要的私人记录。第三方页面适用各自的隐私说明。

查看、备份和删除

你可在软件中查看、修改或删除记录，也可在设置中打开资料库文件夹。卸载软件不会替你删除所选文件夹中的资料库；若需要删除全部记录，请自行处理该文件夹及个人备份。匿名统计不包含可用于定位个人正文记录的信息。
